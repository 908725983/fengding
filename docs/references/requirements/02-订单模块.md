## 一、模块概述

订单模块是蜂订系统的核心业务模块，涵盖从客户下单、审核、出库、发货、收款到统计分析的全生命周期管理。

### 1.1 子模块结构

```
订单
├── 客户订单
│   ├── 客户订单（订单列表/筛选/详情/新增/分享订单）
│   └── 客户退单（退单列表/筛选/详情/新增）
├── 差异单列表（列表/详情）
├── 销售管理
│   └── 销售出库单（列表/筛选/详情）
├── 订单统计
│   ├── 订单商品明细（明细/筛选）
│   ├── 退单商品明细（明细/筛选）
│   ├── 订单商品汇总-按商品（汇总/筛选）
│   ├── 订单商品汇总-按客户（汇总/筛选）
│   ├── 预售商品明细（明细/筛选）
│   └── 预售商品汇总-按商品（汇总/筛选）
├── 销售统计
│   ├── 订单出入库明细（明细/筛选）
│   ├── 订单出入库汇总-按商品（汇总/筛选）
│   └── 订单出入库汇总-按客户（汇总/筛选）
```

#### 2.3.2 状态流转（截图显示为4步时间轴）

```
待订单审核 → 待财务审核 → 已审核 → 出库 → 发货 → 完成
                        ↑                                                  
                   可回退至待订单审核
```

| 状态节点 | 说明 |
|----------|------|
| **待订单审核** | 等待业务主管审核 |
| **待财务审核** | 等待财务人员审核（可回退至待订单审核） |
| **已审核** | 审核全部通过，等待出库 |
| **出库** | 仓库完成出库操作 |
| **发货** | 物流确认发货 |
| **完成** | 客户签收确认，订单完成 |

> 详情页时间轴精简展示为：审核 → 出库 → 发货 → 完成。完整状态含6步流转，支持待财务审核→待订单审核回退。

### 2.4 订单状态流转

```
待订单审核 → 待财务审核 → 已审核(待出库) → 出库中 → 已出库(待发货) → 已发货(待签收) → 已完成
     │            │              │              │              │
     └─取消       └─回退至       └─差异单       └─差异单       └─差异单
                  待订单审核
```

> 无独立"编辑订单"页面。已审核前可退回修改，已审核后不可编辑。需修改已审核订单时，通过作废/取消后重新下单。

| 状态 | 可执行操作 | 操作人 |
|------|------------|--------|
| **待订单审核** | 审核/退回/取消 | 业务主管 |
| **待财务审核** | 财务审核/回退至待订单审核 | 财务人员 |
| **已审核(待出库)** | 出库/打印拣货单 | 仓库人员 |
| **出库中** | 继续出库 | 仓库人员 |
| **已出库(待发货)** | 确认发货/填写物流单号 | 仓库/物流 |
| **已发货(待签收)** | 确认签收 | 仓库/业务员 |
| **已完成** | 查看详情/生成退单 | 所有人 |
| **已取消** | 查看详情 | 所有人 |

### 7.2 订单出入库汇总 — 按商品

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 商品编码 | 文本 | SKU编码 |

| 规格 | 文本 | 商品规格 |
| 单位 | 文本 | 计量单位 |
| 数量 | Number | 总出入库数量 |
| 单价 | 货币 | 平均单价 |

### 7.3 订单出入库汇总 — 按客户

|--------|------|------|

## 八、业务规则汇总

| 规则编号 | 业务规则 | 说明 |
|----------|----------|------|
| ORD-01 | 单号自动生成 | 格式：前缀+YYMMDD+序号，不可修改 |
| ORD-02 | 订单状态单向流转 | 正常流程不可回退（待财务审核→待订单审核除外） |
| ORD-03 | 部分出库生成差异单 | 实出 < 应出时，自动生成差异单 |
| ORD-04 | 退单关联原订单 | 整单退/部分退必须关联原订单 |
| ORD-05 | 退货数量 ≤ 已出库数量 | 不可退未出库的商品 |
| ORD-06 | 退款需审核确认 | 退款必须经过确认退款流程 |
| ORD-07 | 出库扣减库存 | 确认出库时实时扣减可用库存 |
| ORD-08 | 等级价格自动带入 | 选择客户+商品后，自动匹配等级价格 |
| ORD-09 | 商品授权校验 | 客户只能订购已授权的商品 |
| ORD-10 | 分享订单有效期 | 分享链接过期后无法查看/确认 |
| ORD-11 | 预收占用 | 下单时自动占用客户预收金额 |
| ORD-12 | 特价订单标记 | 特价订单需走特殊审批流程 |
| ORD-13 | 出库作废可恢复 | 已作废的出库单可查看并重新出库 |
| ORD-14 | 自定义属性可配置 | 自定义属性字段在设置中可扩展 |
| ORD-15 | 二维表设置 | 统计报表支持自定义二维表展示维度 |
