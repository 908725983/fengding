# 蜂订全渠道营销系统 — PC端需求文档（六）：客户模块

> 版本：v2.0（Clean） | 基准：铱云易订货系统 | 日期：2026-06-06

## 一、模块概述

客户模块是蜂订系统的客户关系管理(CRM)中心，涵盖客户管理、公海池、外勤拜访、会员体系、营销活动、积分体系、商城运营及营销分析。

### 1.1 子模块结构

```

├── 客户管理
│   ├── 客户列表
│   ├── 客户详情（多Tab）
│   ├── 商机列表
│   ├── 客户常购商品
│   ├── 客户分类
```

系统自动将符合以下条件的商品标记为常购商品：
- 最近3个月内购买次数 ≥ 3次
- 或最近6个月内购买次数 ≥ 5次
- 或累计购买金额 ≥ 1000元

#### 2.9.3 领取/分配操作

**领取客户：**
- 业务员领取公海客户成为自己的客户
- 受每日/每月领取上限限制
- 领取后进入保护期

**分配客户：**
- 管理员将公海客户分配给指定业务员
- 不受领取上限限制
- 分配后进入保护期

**批量分配：**
- 支持选中多个客户批量分配
- 可按地区/分类自动分配给对应业务员

## 九、业务规则

| 编号 | 业务规则 | 说明 |
|------|----------|------|
| CUS-01 | 客户编码唯一 | 同一企业下客户编码不可重复 |
| CUS-02 | 公海自动回收 | 超过设定天数未下单/未拜访的客户自动回收到公海 |
| CUS-03 | 公海领取限制 | 业务员每日/每月可领取公海客户数量限制 |
| CUS-04 | 拜访签到定位 | 拜访必须GPS签到，记录位置信息 |
| CUS-05 | 优惠券类型 | 支持满减券/折扣券/直减券/免运费券四种类型 |
| CUS-06 | 优惠券限领 | 每人限领数量控制，防止刷单 |
| CUS-07 | 促销互斥 | 同一商品不可同时参与多个促销活动 |
| CUS-08 | 积分获取上限 | 每日/每笔订单可获取积分上限控制 |
| CUS-09 | AI标签确认 | AI建议的标签需人工确认后生效 |
| CUS-10 | 客户分类折扣 | 客户分类折扣率在下单时自动应用 |
| CUS-11 | 会员等级升级 | 达到升级条件自动或手动升级会员等级 |
| CUS-12 | 地图定位 | 客户地址可在地图上可视化展示 |
