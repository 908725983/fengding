# 蜂订全渠道营销系统 — PC端需求文档（四）：采购模块

> 版本：v2.0（Clean） | 基准：铱云易订货系统 | 日期：2026-06-06

---

## 一、模块概述

采购模块负责从供应商端的采购全流程管理，包括商品补货分析、智能采购订单、采购订单/退单管理、快速采购、供应商管理、直送供应统计及采购统计分析。

### 1.1 子模块结构

```
采购
├── 采购管理
│   ├── 商品补货分析
│   ├── 智能采购订单
│   ├── 采购订单
│   ├── 采购退单
│   └── 快速采购
│       ├── 按库存采购
│       ├── 按订单采购
│       └── 快速采购列表
├── 供应商管理
│   ├── 供应商列表
│   └── 供应商供货商品
├── 直送供应统计
├── 采购出入库单
└── 采购统计
    ├── 采购订单明细
    ├── 采购订单汇总-按供应商
    ├── 采购出入库明细
    ├── 采购出入库汇总-按商品
    └── 采购出入库汇总-按供应商
```

## 二、采购管理

### 2.1 商品补货分析

| Tab | 说明 |
|-----|------|
| 按安全库存分析 | 基于安全库存阈值生成补货建议 |
| 按缺货分析 | 基于当前缺货情况生成补货建议 |

#### 2.1.2 筛选条件

| 筛选字段 | 类型 | 说明 |

#### 2.3.3 采购订单详情

展示完整的订单信息，包括：
- 基本信息（单号/供应商/下单时间/收货信息/备注）
- 商品明细列表
- 入库记录
- 付款记录
- 操作日志

#### 2.3.4 采购订单状态流转

```
待审核 → 已审核 → 部分入库 → 已完成
   │         │
   └─作废    └─取消(未入库时)
```

| 状态 | 可执行操作 |
|------|------------|
| 待审核 | 审核/编辑/作废 |
| 已审核 | 入库/编辑(部分)/取消(未入库) |
| 部分入库 | 继续入库/完成 |
| 已完成 | 查看/生成退单 |
| 已作废 | 查看 |

### 2.5 快速采购

弹窗形式，基于销售订单需求生成采购建议。

**筛选条件：**

| 筛选字段 | 类型 | 说明 |

| 下单时间 | 日期范围 | 订单下单时间 |

## 七、业务规则

| 编号 | 业务规则 | 说明 |
|------|----------|------|
| PUR-01 | 商品补货分析 | 基于安全库存、缺货情况自动生成补货建议 |
| PUR-02 | 智能采购订单 | 基于补货分析一键生成采购订单，支持按库存/按订单两种模式 |
| PUR-03 | 供应商商品关联 | 采购前必须先建立供应商与商品的供货关系 |
| PUR-04 | 采购订单状态流转 | 待审核 → 已审核 → 部分入库 → 已完成 |
| PUR-05 | 采购入库增加库存 | 确认入库时实时增加目标仓库库存 |
| PUR-06 | 采购退货扣减库存 | 采购退单出库时扣减库存。建议关联原采购单，校验退货数量≤已入库数量 |
| PUR-07 | 三重回单状态 | 退单有退单状态、出库状态、退款状态三重状态跟踪 |
| PUR-08 | 直发供应 | 支持供应商直发客户场景，单独统计 |
| PUR-09 | 采购单号规则 | 格式：PO + YYMMDD + 6位序号 |
| PUR-10 | 快速采购筛选 | 支持多维度筛选（单据状态/出库状态/收款状态/配送方式） |
