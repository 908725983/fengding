# 蜂订全渠道营销系统 — PC端需求文档（五）：库存模块

> 版本：v2.0（Clean） | 基准：铱云易订货系统 | 日期：2026-06-06

---

## 一、模块概述

库存模块负责仓库库存的全生命周期管理，包括库存查询、仓库与储位管理、出入库操作、盘点管理、成本调整、库存结转、加工管理、分拣配送及库存统计分析。

### 1.1 子模块结构

```
库存
├── 库存查询
│   ├── 库存列表
│   ├── 批次库存列表
│   ├── 出入库明细
│   └── 批次出入明细
├── 仓库管理
│   ├── 仓库列表
│   └── 库位列表
├── 库存管理
│   ├── 转仓单
│   ├── 其他出库单
│   ├── 其他入库单
│   ├── 盘点记录
│   ├── 成本调整单
│   └── 库存结转
├── 加工管理
│   ├── 加工配方
│   ├── 加工计划
│   ├── 加工单
│   ├── 加工领料单
│   ├── 加工退料单
│   └── 原料出成率统计
├── 分拣配送
│   ├── 待出库列表
│   ├── 订单分拣
│   ├── 波次分拣
│   ├── 配送任务
│   ├── 配送线路
│   ├── 车辆管理
│   └── 分拣标签
└── 库存统计
    ├── 进销存统计
    ├── 进销存汇总统计-按仓库
    ├── 出入库汇总
    └── 库存收发仓库统计
```

## 二、库存查询

### 2.2 批次库存列表

按批次维度展示库存，支持批次追溯。

| # | 字段名 | 类型 | 说明 |
|---|--------|------|------|
| 1 | 仓库 | 文本 | 仓库名称 |
| 2 | 商品编码 | 文本 | SKU编码 |
| 3 | 商品名称 | 文本 | 商品名称 |
| 4 | 批次号 | 文本 | 批次唯一标识 |
| 5 | 生产日期 | Date | 商品生产日期 |
| 6 | 有效期至 | Date | 保质期截止日 |
| 7 | 批次数量 | Number | 该批次库存数量 |
| 8 | 成本单价 | 货币 | 该批次成本单价 |
| 9 | 批次金额 | 货币 | 批次数量 × 成本单价 |
| 10 | 入库时间 | DateTime | 批次入库时间 |
| 11 | 状态 | Tag | 正常/临期/过期 |

> **批次管理规则：**
> - 临期：距有效期 ≤ 30天 → 橙色预警
> - 过期：超过有效期 → 红色标签，禁止出库

| 12 | 操作人 | 文本 | 操作人员 |

### 4.6 库存结转

期末库存结转操作，将本期库存结转为下期期初库存。

#### 4.6.1 库存结转页面

**页面布局：** 月份选择卡片式布局

**结转状态显示：**
- 显示"暂无结转记录"或已结转月份列表
- 提示：请选择结转月份

**月份选择器：**

| 字段 | 说明 |
|------|------|
| 年份 | 年份选择器（如 2026年） |
| 月份卡片 | 01月~12月，共12张卡片 |

- 未结转月份：灰色卡片
- 已结转月份：带勾选标记

**操作按钮：**

| 按钮 | 说明 |
|------|------|
| 开始结转 | 对选中的月份执行库存结转 |

#### 4.6.2 结转规则

- 结转后，本月期末库存自动成为下月期初库存
- 已结转月份不可再次结转（除非反结转）
- 结转操作影响进销存统计的期初/期末数据

## 八、业务规则

| 编号 | 业务规则 | 说明 |
|------|----------|------|
| INV-01 | 出库扣减库存 | 确认出库时实时扣减可用库存 |
| INV-02 | 入库增加库存 | 确认入库时实时增加库存 |
| INV-03 | 库存不足拦截 | 可用库存 < 出库数量时不允许出库 |
| INV-04 | 先进先出(FIFO) | 批次出库默认按生产日期从早到晚 |
| INV-05 | 安全库存预警 | 可用库存 ≤ 安全库存时触发预警 |
| INV-06 | 盘点锁定 | 盘点期间禁止出入库操作 |
| INV-07 | 成本加权平均 | 入库时按加权平均法重新计算成本单价 |
| INV-08 | 转仓双重操作 | 转仓需分别确认源仓出库+目标仓入库 |
| INV-09 | 批次临期预警 | 保质期商品距有效期≤30天预警 |
| INV-10 | 分拣差异处理 | 实拣≠应拣时自动生成差异单 |
| INV-11 | 加工配方BOM | 加工需先维护配方，定义成品与原料配比 |
| INV-12 | 加工领料扣减 | 加工领料时扣减原料库存 |
| INV-13 | 加工入库增加 | 加工完工时增加成品库存 |
| INV-14 | 库存结转锁定 | 已结转月份禁止出入库操作 |
| INV-15 | 库位管理 | 商品入库时可指定具体库位，便于分拣定位 |
| INV-16 | 波次合并分拣 | 多订单合并波次，按商品汇总拣货后再分播 |
