# 蜂订全渠道营销系统 — PC端需求文档（三）：商品模块

> 版本：v2.0（Clean） | 基准：铱云易订货系统 | 日期：2026-06-06

---

## 一、模块概述

商品模块负责商品全生命周期管理，包括商品信息维护、价格体系、授权管理、铺货方案、订单模板及辅助资料管理。

### 1.1 子模块结构

```
商品
├── 商品管理
│   ├── 商品列表
│   ├── 新增商品
│   ├── 商品详情（7个Tab）
│   ├── 商品授权方案
│   ├── 授权规则
│   └── 客户特殊授权
├── 价格管理
│   ├── 等级调价单
│   ├── 进价调价单
│   ├── 客户调价单
│   ├── 历史调价明细
│   ├── 按订单批量调价
│   └── 自动调价策略
├── 铺货方案
│   ├── 铺货方案列表
│   ├── 新增铺货方案
│   └── 执行统计
├── 订单模板
│   ├── 模板列表
│   └── 新增模板
└── 辅助资料
    ├── 商品分类
    ├── 商品品牌
    ├── 商品单位
    ├── 商品标签
    ├── 商品智能标签
    └── 展示分类
```

## 二、商品管理

### 2.1 商品列表

#### 2.1.1 页面布局

- **左侧**：分类树形导航面板，展示全部商品分类的树形结构。点击分类节点筛选该分类下的商品。
- **右侧**：商品数据表格 + 筛选区 + 工具栏。

#### 2.1.2 工具栏按钮

| 按钮 | 功能 |
|------|------|
| 刷新 | 刷新列表数据 |
| 导出 | 导出商品数据 |
| 导入 | 批量导入商品 |
| 新增 | 新增商品 |
| 按SKU展示 | 切换至SKU视图 |
| 按SPU展示 | 切换至SPU视图 |

#### 2.1.3 筛选条件

| 筛选字段 | 类型 | 说明 |
|----------|------|------|
| 商品分类 | 级联下拉 | 按商品分类树筛选 |
| 商品品牌 | 下拉选择 | 按品牌筛选 |
| 商品状态 | 下拉 | 上架/下架/草稿 |
| 关键字 | 文本输入 | 商品编码/名称/条码搜索 |
| 更多筛选 | 展开 | 标签/供应商/价格区间等 |

#### 2.1.4 列表字段

| # | 字段名 | 类型 | 说明 |
|---|--------|------|------|
| 1 | 图片 | 复选框+缩略图 | 行首为复选框，其次为商品缩略图 |
| 2 | 名称 | 文本链接 | 商品名称，点击进入详情 |
| 3 | 编码/条码 | 文本 | 商品编码与条码合并展示 |
| 4 | 单位 | 文本 | 计量单位 |
| 5 | 基准进货价 | 货币 | 采购基准价 |
| 6 | 市场价 | 货币 | 市场参考价 |
| 7 | 商品状态 | Tag | 上架/下架/草稿 |
| 8 | 创建时间 | DateTime | 商品创建时间 |

#### 2.1.5 批量操作

| 操作 | 条件 | 说明 |
|------|------|------|
| 批量上架 | 选中商品为"下架"状态 | 修改为上架 |
| 批量下架 | 选中商品为"上架"状态 | 修改为下架 |
| 批量导出 | 至少选中1条 | 导出商品信息 |
| 批量删除 | 选中商品无关联订单 | 物理删除或标记删除 |

#### 2.1.6 分页

- 默认每页30条，支持切换每页条数。

### 2.2 新增商品

- **左侧主区域**（从上到下）：商品信息 → 规格属性 → 价格属性 → 分阶梯订货价 → 商品描述

#### 2.2.2 商品信息区

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 商品标签 | 文本输入 | ✅ | 最多8个字符 |
| 商品分类 | 下拉选择 | ✅ | |

## 三、价格管理

### 价格体系说明

系统采用"完整价格矩阵直接编辑"模型。每个商品拥有6列价格（成本价 + 基准订货价 + 四级阶梯价：一垫/二垫/门店/终端价）。调价单直接编辑完整价格矩阵，而非在原价基础上做增量调整。

---

### 3.1 等级调价单

#### 3.1.1 列表字段

| # | 字段名 | 类型 | 说明 |
|---|--------|------|------|
| 1 | 单号 | 文本 | 自动生成 |

## 七、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| PRD-01 | 商品编码唯一 | 同一企业下商品编码不可重复 |
| PRD-02 | 价格优先级 | 客户价格 > 等级价格 > 基准订货价(市场价) |
| PRD-03 | 授权校验 | 客户只能看到已授权方案+特殊授权的商品 |
| PRD-04 | 调价单定时生效 | 调价单到达生效时间自动生效，无需人工操作 |
| PRD-05 | 下架商品不可新订 | 商品下架后不出现在订货商品选择中 |
| PRD-06 | 多单位体系 | 商品支持库存/采购/分销/销售四维独立单位 |
| PRD-07 | 关联商品推荐 | 下单时自动推荐搭配品/替代品 |
| PRD-08 | 删除保护 | 已有订单关联的商品不可删除，只能下架 |
| PRD-09 | 阶梯价格体系 | 商品支持四级阶梯订货价（一垫/二垫/门店/终端），调价单直接编辑完整价格矩阵 |
| PRD-10 | 授权方案范围 | 授权方案通过"指定分类/品牌+指定商品"定义范围，分类与品牌取交集 |
| PRD-11 | 订单模板自动过滤 | 模板内商品如被淘汰、停售、或取消授权，下单时自动过滤 |
| PRD-12 | 多规格独立编码 | 同一商品的不同规格变体拥有独立编码、条码和主图 |
| PRD-13 | 价格上下限控制 | 商品可设置最高售价和最低售价，防止价格异常 |
| PRD-14 | 展示分类与商品分类解耦 | 展示分类（面向客户）与商品分类（后台管理）独立维护 |
| PRD-15 | 铺货方案自动加购 | 仅移动端自主下单自动加购铺货商品，代下单不检查 |
| PRD-16 | 铺货商品过滤 | 无授权/淘汰/停售商品在铺货时自动过滤；数量受限时自动跳过 |
| PRD-17 | 进价调价范围 | 进价调价单仅管理成本价和基准进货价，不涉及阶梯价格 |
