## 一、模块概述

数据与设置模块负责企业基础数据配置、组织架构管理、系统权限配置及全局业务规则设置。

### 1.1 子模块结构

```
设置
├── 公司信息
│   ├── 公司信息
│   ├── 部门管理
│   └── 内部公告
├── 权限管理
│   ├── 角色管理
│   └── 员工列表
├── 基础资料
│   ├── 区域管理
│   └── 仓库列表
└── 系统管理
    └── 系统日志
```

## 二、公司信息

|--------|------|------|------|

### 2.2 部门管理

组织架构管理，支持树形层级。

#### 2.2.1 部门树形结构

采用树形展示，支持多级部门。

**示例结构：**
```
总部
├── 部门1
│   └── 子部门
├── 部门2
└── ...
```

#### 2.2.2 新增/编辑部门

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 部门名称 | 文本 | ✅ | 部门名称 |
| 上级部门 | 级联选择 | 否 | 父级部门 |
| 部门编码 | 文本 | 否 | 系统自动生成 |
| 部门负责人 | 下拉选择 | 否 | 负责人 |
| 状态 | 单选 | ✅ | 启用/停用 |

#### 2.2.3 业务规则

- **部门层级**：支持多级树形结构，无固定层级限制
- **删除限制**：部门下有员工时不可删除
- **编码规则**：自动生成，格式：DEPT-YYYYMMDD-序号

### 2.3 内部公告

企业内部通知公告管理。

#### 2.3.1 公告列表

**筛选条件：**

| 筛选字段 | 类型 | 说明 |
|----------|------|------|
| 全部 | 下拉 | 状态筛选 |
| 日期范围 | 日期区间 | 发布时间范围 |
| 关键字 | 文本 | 通知标题搜索 |

**工具栏：** 刷新 / 新增

**列表字段：**

| # | 字段名 | 类型 | 说明 |
|---|--------|------|------|
| 1 | 通知标题 | 文本链接 | 公告标题 |
| 2 | 通知类型 | Tag | 公司公告/系统通知等 |
| 3 | 文字轮播 | 文本 | 是否为轮播公告 |
| 4 | 接收对象 | 文本 | 全部员工/指定部门 |
| 5 | 发布人 | 文本 | 发布公告的人员 |
| 6 | 通知状态 | Tag | 已发布/草稿 |
| 7 | 发布时间 | DateTime | 发布/创建时间 |

#### 2.3.2 新增/编辑公告

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 通知标题 | 文本 | ✅ | 最多20字 |
| 通知类型 | 下拉 | ✅ | 公司公告等 |
| 通知内容 | 富文本 | ✅ | 支持AI文案助手、图片、链接 |
| 链接文字 | 文本 | 否 | 点击跳转的链接文字 |
| 链接地址 | 文本 | 否 | http/https开头的链接地址 |
| 接收对象 | 单选 | ✅ | 全部员工 / 指定部门 |
| 推送消息 | 开关 | 否 | 是否推送给员工移动端 |
| 发布人 | 文本 | 否 | 发布公告的人员 |
| 附件 | 文件上传 | 否 | 支持上传附件 |

**链接说明：** 订货端APP中点击链接时，将在APP内直接打开。微信小程序仅支持跳转本商户下的公众号文章，不支持其他网址。链接地址最多300字符。

#### 2.3.3 公告发布流程

```
编辑公告 → 保存草稿 / 立即发布
```

- **草稿状态**：保存后可再次编辑
- **发布状态**：发布后员工在移动端可见
- **推送消息**：开启后，员工接收Push通知

## 四、基础资料

### 4.1 区域管理

销售区域/业务范围管理，支持树形层级。

#### 4.1.1 区域树形结构

采用树形展示，支持多级区域。

**示例结构：**
```
中国 (默认区域)
├── 华北区
├── 华南区
├── 湖南省
├── 涪陵区
├── 广东
├── 市区
├── 某个区域
├── 广州黄埔仓
├── 麦克英孚
├── 省代
└── 华东区
```

#### 4.1.2 新增/编辑区域

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 区域名称 | 文本 | ✅ | 区域名称 |
| 上级区域 | 级联选择 | 否 | 父级区域 |
| 区域编码 | 文本 | 否 | 系统自动生成 |
| 区域类型 | 下拉 | 否 | 大区/省份/城市/区县/仓库等 |
| 状态 | 单选 | ✅ | 启用/停用 |

#### 4.1.3 业务规则

- **区域关联**：客户档案中关联区域，用于客户分配和统计
- **删除限制**：区域下有关联客户时不可删除
- **默认区域**：至少保留一个默认区域

| **联系信息** | | | |
| 联系人 | 文本 | 否 | 负责人姓名 |
| 联系电话 | 文本 | 否 | 联系电话 |
| 所在地区 | 级联选择 | 否 | 省/市/区 |
| 详细地址 | 文本 | 否 | 详细地址 |

#### 4.2.5 业务规则

- **仓库类型**：支持实体仓、虚拟仓、仓位（如车辆作为移动仓位）
- **禁售仓库**：标记为禁售后，该仓库库存不可用于销售出库
- **数据同步**：与`05-库存模块`共用仓库数据，任一入口修改同步更新

## 六、业务规则

| 编号 | 业务规则 | 说明 |
