## 一、系统概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| **系统名称** | 蜂订全渠道营销系统 |
| **产品类型** | B2B 全渠道订货 + 供应链管理 + 营销一体化平台 |
| **核心用户** | 品牌方/厂商运营人员、经销商/客户、业务员、仓库人员、财务人员 |
| **终端覆盖** | PC端（管理后台） + 移动端（商城/订货小程序） |
| **核心价值** | 订货→出库→配送→收款→数据分析 全链路数字化管理 |

| 4 | 🛒 采购 | Procurement | 采购订单/退单/供应商/统计 |
| 5 | 📊 库存 | Inventory | 库存查询/出入库/分拣配送/统计 |
| 6 | 👥 客户 | Customer | 客户/外勤/营销/积分/商城/统计 |
| 7 | 🏪 商家 | Merchant | 商家订单/商家管理/商家统计 |

| 9 | 📈 数据 | Analytics | 商品/客户/业绩/预警/经营/自定义报表 |

## 二、核心业务流程总览

### 2.1 销售主流程（客户下单 → 收款闭环）

```
客户下单 → 订单审核 → 财务审核 → 仓库出库 → 物流发货 → 客户签收 → 确认收款
   │           │           │           │           │           │           │
   ├─ 新增订单  ├─ 待审核   ├─ 待财务审  ├─ 待出库   ├─ 待发货   ├─ 待签收   ├─ 收款单
   ├─ 分享订单  ├─ 审核通过  ├─ 审核通过  ├─ 生成出库单 ├─ 物流跟踪  ├─ 签收确认  ├─ 核销
   └─ 手机端下单└─ 审核驳回  └─ 审核驳回  └─ 打印拣货单 └─ 配送任务  └─ 差异处理  └─ 应收核销
```

### 2.2 退货流程

```
客户申请退货 → 退单审核 → 仓库入库 → 确认退款
      │            │          │          │
   ├─ 新增退单   ├─ 退单审核 ├─ 退回入库 ├─ 退款确认
   └─ 按原单退   └─ 审核驳回 └─ 差异处理 └─ 生成付款单
```

### 2.3 采购流程

```
智能采购建议 → 创建采购订单 → 供应商确认 → 采购入库 → 付款
      │              │             │          │        │
   ├─ 库存预警触发  ├─ 手工新增   ├─ 供应商列表 ├─ 入库单  ├─ 付款单
   └─ 订单需求触发  └─ 智能生成   └─ 采购退单  └─ 批次管理 └─ 应付核销
```

### 2.4 资金流程

```
订单收款 → 收款单 → 核销 → 应收冲销
采购付款 → 付款单 → 核销 → 应付冲销
退款    → 确认退款 → 付款单 → 应付增加
其他    → 其他收入/支出 → 账户转账
```

### 2.5 库存流转

```
采购入库 → 库存增加 → 销售出库 → 库存减少
其他入库 → 库存增加 → 其他出库 → 库存减少
转仓    → 源仓减少 → 目标仓增加
盘点    → 盘盈入库 / 盘亏出库
成本调整 → 库存成本变更
```

## 三、PC端首页（Dashboard）

### 3.1 页面概述

首页作为系统工作台，为不同角色提供待办事项、营业数据、预警通知的一站式入口。

### 3.2 页面区域划分

| 区域 | 位置 | 功能说明 |
|------|------|----------|
| 待办事项 | 页面上方左侧 | 核心待办卡片，快速跳转处理 |
| 待办自定义 | 待办区域右上角 | 自定义显示哪些待办项 |
| 营业情况 | 页面上方右侧 | 核心经营指标卡片 |
| 图表 | 页面中部 | 营业趋势图表 |
| 预警中心 | 页面下方左侧 | 库存/订单/客户预警 |
| 通知公告 | 页面下方右侧 | 系统通知 + 公告推送 |

### 3.3 待办事项

#### 3.3.1 默认待办卡片

| 待办项 | 数据来源 | 点击跳转 | 字段说明 |
|--------|----------|----------|----------|
| **待审核订单** | 订单模块 - 状态为"待审核"的订单数 | 客户订单列表（筛选待审核） | 数字 + 环比变化 |
| **待财务审核** | 订单模块 - 状态为"待财务审核"的订单数 | 客户订单列表（筛选待财务审核） | 数字 + 环比变化 |
| **待出库订单** | 订单模块 - 状态为"待出库"的订单数 | 销售出库单列表 | 数字 + 环比变化 |
| **待发货订单** | 订单模块 - 状态为"待发货"的订单数 | 待出库列表 | 数字 + 环比变化 |
| **待签收订单** | 订单模块 - 状态为"待签收"的订单数 | 客户订单列表（筛选待签收） | 数字 + 环比变化 |
| **待处理退款** | 退单模块 - 状态为"待处理"的退款单数 | 客户退单列表 | 数字 + 环比变化 |

#### 3.3.2 自定义待办

| 功能项 | 类型 | 说明 |
|--------|------|------|
| 自定义入口 | 弹窗/抽屉 | 允许用户选择显示哪些待办卡片 |
| 拖拽排序 | 拖拽交互 | 支持调整待办卡片顺序 |
| 保存偏好 | 本地存储 | 用户的自定义布局持久化 |

### 3.4 营业情况

#### 3.4.1 指标卡片

| 指标名 | 计算逻辑 | 展示格式 | 时间范围 |
|--------|----------|----------|----------|
| **今日订单数** | 当日已完成 + 进行中订单总数 | 数字 + 环比/同比箭头 | 今日 vs 昨日 |
| **今日销售额** | 当日订单金额总和 | ¥金额 + 环比/同比箭头 | 今日 vs 昨日 |
| **今日收款额** | 当日确认收款的金额总和 | ¥金额 + 环比/同比箭头 | 今日 vs 昨日 |
| **待收金额** | 未核销的应收金额合计 | ¥金额 | 截至当前 |

#### 3.4.2 趋势图表

| 图表项 | 图表类型 | 维度 | 说明 |
|--------|----------|------|------|
| **销售额趋势** | 折线图/柱状图 | 按日/周/月 | 支持切换时间维度 |
| **订单量趋势** | 折线图/柱状图 | 按日/周/月 | 支持切换时间维度 |
| **对比维度** | 多选切换 | 本期 vs 同期 | 支持同比/环比对比 |

### 3.5 预警中心

| 预警类型 | 触发条件 | 展示形式 | 操作 |
|----------|----------|----------|------|
| **库存不足预警** | 商品可用库存 ≤ 预警值 | 红色/橙色标签 | 点击跳转库存列表 |
| **订单超时预警** | 订单超过预期时间未处理 | 红色标签 | 点击跳转订单详情 |
| **应收逾期预警** | 应收账款超过账龄天数 | 红色标签 | 点击跳转应收账款 |
| **客户风险预警** | 客户信用额度不足等 | 橙色标签 | 点击跳转客户详情 |

### 3.6 通知公告

| 功能项 | 类型 | 说明 |
|--------|------|------|
| **系统通知** | 通知列表 | 订单状态变更、审批通知等 |
| **公告推送** | 公告列表 | 管理员发布的通知公告 |
| **已读/未读** | 状态标记 | 未读加粗/红点提示 |
| **全部已读** | 按钮 | 一键标记所有通知为已读 |

## 四、全局交互规范

### 4.1 列表页通用规范

| 规范项 | 说明 |
|--------|------|
| **默认排序** | 按创建时间倒序（最新在前） |
| **分页** | 默认 30 条/页，可选 10/30/50/100 |
| **筛选区** | 默认收起常用筛选，"更多筛选"展开高级条件 |
| **操作列** | 放在表格最右侧，主操作用主色按钮，次操作用文字链接 |
| **批量操作** | 表头复选框 + 底部操作栏（批量审核/导出/打印等） |
| **空状态** | 无数据时显示引导图 + "暂无数据"文案 + 新增按钮 |

### 4.2 详情页通用规范

| 规范项 | 说明 |
|--------|------|
| **布局** | 左侧基本信息卡片 + 右侧操作日志/状态流 |
| **状态流** | 顶部展示单据流转状态（时间轴形式） |
| **操作区** | 页面顶部右侧，根据状态动态显示可用操作按钮 |
| **Tab切换** | 多信息区域使用 Tab 分区（基本信息/商品明细/收货信息/操作日志） |

### 4.3 新增/编辑页通用规范

| 规范项 | 说明 |
|--------|------|
| **表单布局** | 上下分区：基础信息 → 商品明细 → 附加信息 |
| **必填标识** | 红色星号 * 标注必填项 |
| **保存** | 支持"保存"和"保存并新增"两种模式 |
| **校验** | 实时校验 + 提交时校验，错误信息定位到具体字段 |
| **离开确认** | 未保存时离开页面弹出确认弹窗 |
