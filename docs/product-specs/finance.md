# 资金领域规格

## 目标与范围

跟踪客户应收、供应商应付、收付款、核销和资金账户，使业务单据与资金变化能够相互追溯。

## 主要页面

- 应收/应付列表、按单据/商品明细、账龄分析。
- 核销单列表、新增与明细。
- 收款、付款、退款确认、拉新提现。
- 资金账户、收支明细/汇总、结转、银行和在线支付设置。
- 内部转账、其他收支、机构收款和资金统计。

## 业务规则

| ID | 必须行为 |
|---|---|
| FIN-01 | 收付款与应收应付单据进行匹配核销。 |
| FIN-02 | 按单据日期自动计算账龄区间。 |
| FIN-03 | 每笔确认收付款实时更新资金账户余额。 |
| FIN-04 | 已核销收付款不可删除或修改金额。 |
| FIN-05 | 退款优先原路；特殊情况可选择现金或余额。 |
| FIN-06 | 已资金结转月份禁止资金出入。 |
| FIN-07 | 非业务收付款必须财务审核。 |
| FIN-08 | 转账只允许内部资金账户之间调拨。 |
| FIN-09 | 支持第三方支付通道开通配置。 |
| FIN-10 | 拉新奖励提现审核后打款。 |
| FIN-11 | 多机构模式按机构汇总收款。 |

## 不变量

- 金额为整数分；收付款、已核销、未核销三者关系必须精确且不可为负。
- 一次核销可匹配多张单据，但总核销额不得超过可用收付款额或单据未核销额。
- 账户余额变化和资金流水作为一个结果，重复请求不得重复入账。
- 原始业务单据、收付款与核销单之间可双向追溯。

## P0 验收

1. 收款可分配到多张应收，部分核销后余额正确；超额核销被拒绝。
2. 已核销收款不能删除或改金额，未核销草稿按权限可操作。
3. 确认收款只更新一次账户余额并生成流水。
4. 账龄在模拟日期边界前后进入正确区间。
5. 结转月份的收付款、退款与转账均被拦截。
6. 退款显示原支付方式，改用其他方式时记录原因。

## 原型模拟边界

不接入微信、支付宝、银联、银行或真实打款；支付设置只展示配置流程，所有支付结果标记为模拟。
