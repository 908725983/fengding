# 商品领域规格

## 需求来源与事实边界

- 直接业务来源：[03-商品模块.md](../references/requirements/03-商品模块.md)；列表、详情、表单和权限共性来自 [01-整体架构与首页.md](../references/requirements/01-整体架构与首页.md) §4～§5。
- 功能切片、章节、依赖、规则归属和字段准备度以 [产品规格索引](index.md) 为唯一目录。
- `PRD-01～PRD-17` 直接整理自原文 §7。价格服务、精确单位换算和可控时钟属于 Harness 工程约束。
- 客户分类折扣、会员折扣、客户价、等级价、促销和优惠券的组合顺序尚未确认；多个授权机制同时命中的优先级、单位换算语义与精度也未定义。分别按 `DEC-PRD-001`、`DEC-PRD-002`、`DEC-PRD-003` 处理。`PRD-001` 的其余细粒度缺口见本文件契约和产品规格索引中的 `DEC-PRD-004～012`。

## 目标与范围

管理商品/SKU、价格、客户可见范围和订货配置，为订单、采购和库存提供统一商品事实。包含商品管理、授权方案与规则、调价、铺货、订单模板和辅助资料。

## 主要页面

- 商品列表、新增/编辑、多 Tab 详情。
- 授权方案、授权规则、客户特殊授权。
- 等级/进价/客户调价单、历史调价、批量与自动调价。
- 铺货方案、订单模板。
- 分类、品牌、单位、标签、展示分类等辅助资料。

## 业务规则

| ID | 必须行为 |
|---|---|
| PRD-01 | 同一企业内商品编码唯一。 |
| PRD-02 | 售价优先级为客户价格 > 等级价格 > 基准订货价。 |
| PRD-03 | 客户只看到授权方案和特殊授权覆盖的商品。 |
| PRD-04 | 调价单到生效时间自动生效。 |
| PRD-05 | 下架商品不能被新订单选择。 |
| PRD-06 | 库存、采购、分销、销售支持独立单位及明确换算。 |
| PRD-07 | 下单时可推荐搭配品或替代品。 |
| PRD-08 | 已有关联订单的商品不可删除，只能下架。 |
| PRD-09 | 支持四级阶梯订货价及完整价格矩阵。 |
| PRD-10 | 授权范围由指定分类/品牌与指定商品定义，分类和品牌取交集。 |
| PRD-11 | 模板中的淘汰、停售或取消授权商品在下单时自动过滤。 |
| PRD-12 | 多规格变体拥有独立编码、条码和主图。 |
| PRD-13 | 最高/最低售价限制异常价格。 |
| PRD-14 | 客户展示分类与后台商品分类独立维护。 |
| PRD-15 | 自动加购仅用于移动端自主下单，代下单不检查。 |
| PRD-16 | 铺货时过滤无授权、淘汰、停售商品；数量受限时跳过。 |
| PRD-17 | 进价调价只管理成本价和基准进货价，不改阶梯售价。 |

## 关键计算

价格解析服务接收客户、SKU、数量、时间和下单渠道，返回价格、命中来源和拒绝原因；订单页面不得自行比较价格。单位换算应保存原文给出的换算关系，禁止默认为 1；精度、价格换算和舍入在 `DEC-PRD-003` 决定前不得自行补齐。

## P0 验收

1. 新建重复商品/SKU 编码被拒绝；多规格各自保存编码与条码。
2. 对相同 SKU 分别验证客户价、等级价和基准价的命中及来源。
3. 未授权、下架和超价格上下限场景被明确拦截。
4. 已关联订单的商品不可删除但可下架。
5. 调价单在模拟时钟到点前后返回不同价格，重置后恢复基线。
6. 列表、详情、表单覆盖 loading/empty/error/permission-denied。

## 原型模拟边界

定时生效使用可控模拟时钟；智能标签不调用 AI；批量导入导出只展示校验结果。图片使用无品牌的占位素材。

## PRD-001 字段与交互契约

### 事实来源

- 直接业务事实：`03-商品模块.md §2.1～§2.3 Tab 1、§6.3、§7`。
- 全局交互与角色资料：`01-整体架构与首页.md §4～§5`。
- 规则范围：`PRD-01`、`PRD-05`、`PRD-06`、`PRD-08`、`PRD-12`、`PRD-13`；`PRD-02～04` 和 `PRD-07、09～11、14～17` 属于后续价格、授权、铺货或辅助资料切片。
- 工程约束：路由命名、金额以分存储、Repository/Service 分层、确定性 Mock、安全富文本和 fake 文件适配器不新增业务行为。

| 字段标识 | 原文字段 | 类型 | 必填 | 已知校验/来源 | 未决行为 |

### 详情与操作矩阵

商品详情的本切片内容为商品描述 Tab：基础信息卡片展示编码、名称、分类、品牌、规格、单位、价格和状态；图片区域展示主图与轮播图；描述区域安全渲染富文本。右侧保留状态与操作记录，但具体记录事件和顶部动作未定义（`DEC-PRD-012`）。

| 操作 | 来源条件 | 前置校验/副作用 | 未决事项 |
|---|---|---|---|
| 刷新 | 列表工具栏 | 重新加载当前 query，不修改数据 | 已定义 |
| 新增/编辑/查看详情 | 全局与模块页面 | 经 route → UI → service 三层权限 | 角色矩阵见 `DEC-PRD-010` |
| 上架 | 仅下架商品；草稿是否可上架未说明 | 改变订货可选性（`PRD-05`） | 状态机与混合批量见 `DEC-PRD-005` |
| 下架 | 仅上架商品 | 新订单不可选择；历史引用保留 | 状态机与确认文案见 `DEC-PRD-005` |
| 删除 | 无关联订单 | `PRD-08` 要求有关联订单时拒绝 | 物理/标记删除、其他引用及批量原子性见 `DEC-PRD-005` |
| 导入/导出 | 工具栏或批量栏 | 必须使用 fake adapter 并明确原型模拟 | 文件契约、冲突与权限见 `DEC-PRD-009`、`DEC-PRD-010` |
| 清空/保存/保存并新增 | 表单顶部 | 实时与提交校验，脏数据离开提示 | 精确导航和重置结果见 `DEC-PRD-012` |

所有失败必须返回可理解原因；命令失败不得留下部分 SKU、状态或导入行。

### 状态与计算

- 商品状态原文明确定义 `草稿/上架/下架`，但初始状态、合法转换、单个操作和 SKU 是否独立有状态未定义（`DEC-PRD-005`）。
- `PRD-01`：同一企业商品编码唯一；与 SKU 编码、自动序列、删除后复用的关系未定义（`DEC-PRD-004`）。
- `PRD-05`：下架商品不能被新订单选择；本切片只维护状态，不实现订单选品。
- `PRD-06`：库存、采购、分销、销售使用独立单位；换算锚点、精度、舍入和单位停用影响未定义（`DEC-PRD-003`）。
- `PRD-08`：有订单关联的商品不可删除，只能下架；引用范围和删除方式未定义（`DEC-PRD-005`）。
- `PRD-12`：不同规格变体拥有独立编码、条码和主图；完整 SKU 属性模型未定义（`DEC-PRD-004`）。
- `PRD-13`：最高/最低售价限制异常价格；受控价格集合及比较边界未定义（`DEC-PRD-008`）。
- 创建时间由可注入 clock 生成；界面按本地时区显示到分钟，不以真实系统时间制造不确定 fixture。

| partial-failure | 商品成功，分类/品牌/单位/标签等某个 provider 失败 | 对应字段显示不可用并允许重试 | 禁止用空选项覆盖已存关系 |
| boundary | 重复编码、无 SKU、非法金额/单位、有关联订单删除、混合批量 | 定位具体字段/行 | 原子回滚并保留输入 |

- 唯一 baseline 保存商品、SKU、单位引用、标签引用、状态、价格资料、创建时间和模拟关联标志；各场景从同一 baseline 派生，不另造相互矛盾的数据源。
- 辅助资料和供应商未实现时由只读 fake provider 返回明确的“未接入/不可用”，页面不得直接导入其 fixture。
- 媒体、富文本图片、导入导出和教程均使用 fake adapter，界面显示“原型模拟”，不访问真实文件服务或外部网络。
