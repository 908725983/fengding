# 商品领域规格

## 需求来源与事实边界

- 直接业务来源：[03-商品模块.md](../references/requirements/03-商品模块.md)；列表、详情、表单和权限共性来自 [01-整体架构与首页.md](../references/requirements/01-整体架构与首页.md) §4～§5。
- 功能切片、章节、依赖、规则归属和字段准备度以 [产品规格索引](index.md) 为唯一目录。
- `PRD-01～PRD-17` 直接整理自原文 §7。价格服务、精确单位换算和可控时钟属于 Harness 工程约束。
- 客户分类折扣、会员折扣、客户价、等级价、促销和优惠券的组合顺序尚未确认；多个授权机制同时命中的优先级也未定义，分别按 `DEC-PRD-001`、`DEC-PRD-002` 处理。`PRD-001` 的单位与细粒度契约已由用户确认 `DEC-PRD-003～012` 并写回本文件。

## 目标与范围

管理商品/SKU、价格、客户可见范围和订货配置，为订单、采购和库存提供统一商品事实。包含商品管理、授权方案与规则、调价、铺货、订单模板和辅助资料。

## 主要页面

- 商品列表、新增/编辑、多 Tab 详情。
- 授权方案、授权规则、客户特殊授权。
- 等级/进价/客户调价单、历史调价、批量与自动调价。
- 铺货方案、订单模板。
- 分类、品牌、单位、标签、展示分类等辅助资料。

## 业务规则

| ID | 必须行为 |
|---|---|
| PRD-01 | 同一企业内商品编码唯一。 |
| PRD-02 | 售价优先级为客户价格 > 等级价格 > 基准订货价。 |
| PRD-03 | 客户只看到授权方案和特殊授权覆盖的商品。 |
| PRD-04 | 调价单到生效时间自动生效。 |
| PRD-05 | 下架商品不能被新订单选择。 |
| PRD-06 | 库存、采购、分销、销售支持独立单位及明确换算。 |
| PRD-07 | 下单时可推荐搭配品或替代品。 |
| PRD-08 | 已有关联订单的商品不可删除，只能下架。 |
| PRD-09 | 支持四级阶梯订货价及完整价格矩阵。 |
| PRD-10 | 授权范围由指定分类/品牌与指定商品定义，分类和品牌取交集。 |
| PRD-11 | 模板中的淘汰、停售或取消授权商品在下单时自动过滤。 |
| PRD-12 | 多规格变体拥有独立编码、条码和主图。 |
| PRD-13 | 最高/最低售价限制异常价格。 |
| PRD-14 | 客户展示分类与后台商品分类独立维护。 |
| PRD-15 | 自动加购仅用于移动端自主下单，代下单不检查。 |
| PRD-16 | 铺货时过滤无授权、淘汰、停售商品；数量受限时跳过。 |
| PRD-17 | 进价调价只管理成本价和基准进货价，不改阶梯售价。 |

## 关键计算

价格解析服务接收客户、SKU、数量、时间和下单渠道，返回价格、命中来源和拒绝原因；订单页面不得自行比较价格。经 `DEC-PRD-003` 确认：SPU 基本单位为换算锚点且换算率为 1；四维场景单位默认基本单位，`1 场景单位 = N 基本单位`；换算率最多 6 位小数、数量最多 3 位小数，金额按比例换算后四舍五入到分。

## P0 验收

1. 新建重复商品/SKU 编码被拒绝；多规格各自保存编码与条码。
2. 对相同 SKU 分别验证客户价、等级价和基准价的命中及来源。
3. 未授权、下架和超价格上下限场景被明确拦截。
4. 已关联订单的商品不可删除但可下架。
5. 调价单在模拟时钟到点前后返回不同价格，重置后恢复基线。
6. 列表、详情、表单覆盖 loading/empty/error/permission-denied。

## 原型模拟边界

定时生效使用可控模拟时钟；智能标签不调用 AI；批量导入导出只展示校验结果。图片使用无品牌的占位素材。

- 直接业务事实：`03-商品模块.md §2.1～§2.3 Tab 1、§6.3、§7`。
- 全局交互与角色资料：`01-整体架构与首页.md §4～§5`。

### 表单与校验

表单按商品信息、规格属性、价格属性、阶梯订货价、商品描述排列，右侧为商品标签、默认单位、辅助属性、物流属性和自定义属性。必填字段实时校验并在提交时再次校验。

| 字段标识 | 原文字段 | 类型 | 必填 | 校验/来源 | 确认行为 |
|---|---|---|---|---|---|
| `name` | 商品标签（确认为商品名称） | 文本 | 是 | 去除首尾空格后 1～80 字符 | 列表、详情统一显示为“商品名称” |
| `categoryId` | 商品分类 | 单选 | 是 | 新选项仅启用分类 provider | 已保存的停用分类只读回显，不可重新选择 |
| `baseUnitId` | 计量单位 | 单选 | 是 | 启用单位 provider；“更多设置”指向 `PRD-005` | SPU 级换算锚点，换算率固定 1 |
| `productType` | 商品类型 | 单选 | 否 | 默认普通商品 | 拼套商品本切片禁用并显示“规划中” |
| `productCode` | 商品编码 | 文本 | 是 | 手工输入或生成 `SPU-000001`；同企业 SPU 唯一 | 序号不复用；删除后仍占用编码；已保存编码可编辑但仍校验唯一 |
| `shortName` | 商品简称 | 文本 | 否 | 最多 20 字符 | 不限制大小写 |
| `displayCategoryId` | 展示分类 | 单选 | 否 | 新选项仅启用展示分类 provider | 已保存停用项只读回显，不可重新选择 |

每个商品至少包含一个 SKU。简单商品自动创建一个规格名为“默认”、规格值为“默认规格”的 SKU；多规格商品的每一行都必须填写规格名和值。SKU 编码使用独立 `SKU-000001` 序列且同企业 SKU 间唯一，序号不复用；条码非必填，填写时 SKU 间唯一。SKU 简称最多 20 字符，不从 SPU 自动覆盖。原文要求的独立主图、编码、简称和条码均保留。

| SKU 简称 | 文本 | 规格级简称 | 可空，最多 20 字符 |
| SKU 条码 | 文本 | 规格级条码 | 可空；非空时 SKU 间唯一 |
| 基准进货价 | 金额 | 采购基准价 | 按 SKU 保存；非负，最多两位小数，不受售价上下限约束 |

- “清空页览”确认为清空表单：有脏数据时二次确认；保存成功回列表，保存并新增进入全新空表单；离开脏表单必须确认；视频教程为“原型模拟”。

### 详情与操作矩阵

商品详情的本切片内容为商品描述 Tab：基础信息卡片展示编码、名称、分类、品牌、规格、单位、价格和状态；图片区域展示主图与最多 5 张轮播图；描述区域安全渲染富文本。顶部按状态与权限显示编辑、上架、下架、删除，右侧记录创建、编辑、状态变更和导入事件。

| 操作 | 来源条件 | 前置校验/副作用 | 结果 |
|---|---|---|---|
| 刷新 | 列表工具栏 | 重新加载当前 query，不修改数据 | 已定义 |
| 新增/编辑/查看详情 | 全局与模块页面 | 超级管理员可写；销售主管、业务员、仓库只读；财务拒绝 | 路由、UI、service 三层一致 |
| 上架 | 草稿或下架商品 | 改为上架并进入新订单可选范围 | 写入状态日志 |
| 下架 | 上架商品 | 新订单不可选择；历史引用保留 | 写入状态日志 |
| 删除 | 草稿/下架且无订单引用 | 标记删除并从默认查询隐藏；编码不复用 | 有引用或上架状态明确拒绝 |
| 导入/导出 | 超级管理员工具栏或批量栏 | UTF-8 CSV fake adapter；导入预览并整批原子提交；有勾选导出勾选，否则导出当前筛选全部 | 媒体和富文本不进入 CSV |
| 清空/保存/保存并新增 | 表单顶部 | 实时与提交校验，脏数据离开提示 | 清空二次确认；保存回列表；保存并新增打开空表单 |

所有失败必须返回可理解原因；命令失败不得留下部分 SKU、状态或导入行。

### 状态与计算

- 商品状态为 `草稿/上架/下架`；新增默认草稿，允许草稿→上架、上架→下架、下架→上架；SKU 继承 SPU 状态，不建立独立状态；全部状态均可编辑资料。
- `PRD-01`：同一企业 SPU 编码唯一，SKU 编码在独立命名空间唯一；自动序列不复用，手工编码冲突拒绝，标记删除后编码仍保留。
- `PRD-05`：下架商品不能被新订单选择；本切片只维护状态，不实现订单选品。
- `PRD-06`：库存、采购、分销、销售使用 SPU 级独立场景单位，默认基本单位；换算率表示 `1 场景单位 = N 基本单位`，最多 6 位小数；数量最多 3 位小数；金额换算后四舍五入到分。停用单位只回显不可新选。
- `PRD-08`：有订单关联的商品不可删除，只能下架；本切片用模拟 `hasOrderReference` 表达订单引用。仅草稿/下架且无订单引用可标记删除；不推测库存/采购引用规则。
- `PRD-12`：每个 SKU 具有规格名、规格值、独立编码、可选唯一条码和独立主图；简单商品自动一个“默认/默认规格”SKU。
- `PRD-13`：SKU 的基准订货价及四级阶梯价必须位于已填写的最低/最高售价范围内，边界包含相等；基准进货价不受售价上下限控制。
- 创建时间由可注入 clock 生成；界面按本地时区显示到分钟，不以真实系统时间制造不确定 fixture。

### 已确认执行口径

- 价格模型：SKU 增加独立成本价；与基准进货价、基准订货价、四级价和售价上下限分别保存。界面统一称“一批/二批”，“一垫/二垫”仅保留为来源别名。
- 状态与时钟：单号按 `LPA/PPA/CPA-YYYYMMDD-####` 分类型递增；保存即待生效，待生效可编辑/删除；生效后不可改，被后续版本覆盖时失效；“是否生效”由状态派生。生效分钟不得早于模拟当前分钟，相等则立即原子生效。
- 作用范围：等级调价维护全局 SKU 完整矩阵；表头价格类型只是公式锚点/视图焦点。客户分类增加 `base-order/tier-one/tier-two/store/terminal` 价格层级，默认基准订货价，客户按最近有效分类继承；客户调价只针对单个启用客户。
- 单位价格：三类调价单默认写基本单位；按订单页可写 `SKU + 销售单位` 显式覆盖。无覆盖时按已确认换算率派生并四舍五入到分，售价上下限换算到同单位后校验。
- 版本冲突：相同 scope/SKU/单位/字段按生效时间形成版本，后版本到点覆盖并令旧版本失效；相同生效分钟拒绝，整张单据要么全部生效要么全部回滚。
- 客户状态：新建客户调价只可选启用客户；其他状态的旧价保留但价格解析先以不可下单拒绝，恢复启用后继续使用最新有效版本。
- 筛选/批量：单号、生成/生效日期、状态、制单人为公共筛选，客户单增加客户；原型以 UTF-8 CSV 代替 Excel，预览逐行校验并整批提交。公式支持直接设值、固定额增减、百分比增减，必须选择目标字段，以当前显示值为基数并到分。
- 历史/订单：每个单据明细 × SKU × 单位 × 实际变更字段生成一条不可变历史；相关订单由后续 `ORD` provider 提供，当前显示“数据源未接入”。
- 自动策略：每个 SKU+单位+目标售价最多一个启用策略；锚点限成本价/基准进货价/基准订货价，幅度为固定额或百分比，支持启停和起止分钟；只基于原始锚点、不链式引用策略结果，越界时本次失败、保留旧价并写日志。
- 权限：超级管理员完整读写和导出；销售主管只读售价/历史并遮蔽成本与进价；业务员、仓库只读当前有效售价并遮蔽成本、进价和客户身份；财务按原权限矩阵不可进入。路由、UI 和 Service 三层一致。
- `DEC-PRD-001` 不在本切片强行关闭：`PRD-002` 只返回客户价 > 分类映射等级价 > 基准订货价的预营销价格、命中来源及拒绝原因；分类/会员折扣、促销和优惠券的最终成交组合留给 `CUS-003/CUS-006/ORD-002`。

`DEC-PRD-013～022` 已由用户在 2026-08-11 要求全部按推荐方案执行并写回；`PRD-002` 达到 `ready`，允许在 implementation 计划阶段实现，但不代表功能已经完成。

### 列表、筛选与字段

所有独立列表继承创建时间倒序、默认 30 条/页、10/30/50/100 分页、空状态、刷新和操作列规则。原文没有给授权列表筛选、分页例外或批量动作，具体最小筛选与树行为由 `DEC-PRD-030` 决定。

| 对象 | 原文明示列表字段 | 来源/展示口径 |
|---|---|---|
| 授权方案 | 授权方案名称、商品数量、状态 | 名称为树形文本；商品数必须来自方案范围解析的去重 SPU 数，不能把 SKU 行数当商品数 |
| 授权规则 | 规则名称、生效周期、生效时段 | 名称是编辑链接；多个时段需完整展示或明确折叠计数，不丢失边界 |
| 特殊授权 | 客户名称、客户分类、授权商品数、授权类型、有效期、操作 | 客户和分类来自 CUS provider；商品数按去重 SPU；有效期为空显示“永久” |
| 商品详情方案 | 方案名称、方案编码、适用客户、包含商品、状态、创建时间 | 只展示与当前商品范围命中的方案；适用客户的口径受 `DEC-PRD-025` 阻塞 |
| 商品详情特殊授权 | 客户名称、授权类型、有效期、备注 | 只展示当前商品对应记录；备注仅原文详情 Tab 出现，独立添加页是否保存受 `DEC-PRD-026` 处理 |

### 授权方案表单与范围

| 字段 | 类型/必填 | 已知事实 | 未定义行为 |
|---|---|---|---|
| 方案名称 | 文本/是 | 独立新增页唯一明确必填字段 | 长度、唯一性由 `DEC-PRD-023` 决定 |
| 方案编码 | 文本 | 商品详情 Tab 声明自动生成 | 格式、唯一性、编辑性由 `DEC-PRD-023` 决定 |
| 上级方案 | 树选择 | 列表明确为树形，但表单没有该字段 | 是否真实层级及继承由 `DEC-PRD-023` 决定 |
| 状态 | 启用/停用 | 列表与商品详情均显示 | 默认、转换和停用影响由 `DEC-PRD-023` 决定 |
| 商品分类 | 选择 | 与品牌同时指定时取交集 | 是否包含后代、空值语义由 `DEC-PRD-024` 决定 |
| 商品品牌 | 选择 | 与分类同时指定时取交集 | 多选/单选和空值语义由 `DEC-PRD-024` 决定 |
| 指定商品 | 商品多选 | 在分类/品牌范围外额外授权；可按编码/名称/规格/条码搜索 | SPU/SKU 粒度、重复与上下架处理由 `DEC-PRD-024` 决定 |
| 适用客户 | 客户多选 | 商品详情 Tab 列出；规则另有客户范围 | 直接关联与规则关系由 `DEC-PRD-025` 决定 |

`PRD-10` 已确认的集合骨架是：分类和品牌同时指定时取交集，指定商品再作为额外集合；但分类后代、多分类/品牌、SPU/SKU 粒度、空范围和动态更新尚未定义。任何实现不得在 `DEC-PRD-024` 决定前选择集合算法。

### 授权规则表单

| 字段 | 类型 | 必填/校验 | 已知事实与边界 |
|---|---|---|---|
| 规则名称 | 文本 | 是；不超过20字 | 是否唯一由 `DEC-PRD-027` 决定 |
| 生效周期 | 周期类型 + 周次多选 | 是 | 原文只举“每周、周一～周日”示例，支持的周期集合未定义 |
| 生效时段 | 一个或多个时间区间 | 是 | 支持新增多个时段；跨日、重叠、端点和时区未定义 |
| 授权方案 | 单选 | 是 | 来源为已有方案；停用方案和后续停用影响未定义 |
| 客户范围 | 搜索多选 | 是 | 按客户名称/编码搜索；客户名称/编码只读回显 |

规则只决定“何时把某方案应用于哪些客户”，不复制方案商品集合。解析必须接收客户、商品/SKU 和可控时间，返回 `visible`、`orderable`、命中来源及拒绝原因；页面不得自行组合规则。

### 客户特殊授权表单

| 字段 | 类型 | 必填/来源 | 已知事实与边界 |
|---|---|---|---|
| 选择客户 | 搜索多选 | 是；CUS provider | 仅启用客户可新增是基于已决定 `CUS-001` 下单前置，但旧记录保留方式由 `DEC-PRD-026` 固化 |
| 授权类型 | 单选 | 是 | `可见+可订`、`仅可见`、`禁止` 三值，不得合并 |
| 选择商品 | 商品批量选择 | 是；PRD provider | 原文称商品，默认不能擅自降为单个 SKU |
| 有效期 | 日期范围 | 否 | 不填永久；端点精度与包含关系由 `DEC-PRD-026` 决定 |
| 备注 | 文本 | 商品详情 Tab 明示 | 独立添加页遗漏备注，是否必填/长度由 `DEC-PRD-026` 决定 |

批量添加必须是原子命令；如果任一客户/商品/时间或重叠记录非法，整批拒绝且不产生部分授权。

### 详情、操作与副作用

| 操作 | 来源事实 | 未定义且必须决策的副作用 |
|---|---|---|
| 新增/编辑方案 | 独立管理页和商品详情关联弹窗 | 编码、层级、停用、范围变化如何影响当前授权 |
| 关联方案到商品 | 商品详情可搜索多选方案并确认 | 是加入指定商品集合还是建立独立关系；推荐统一写入方案显式商品集合，受 `DEC-PRD-024` 决定 |
| 导入/导出方案商品 | 工具栏导入导出；批量导入前必须先保存 | 文件列、错误处理、范围和原子性由 `DEC-PRD-028` 决定 |
| 编辑/删除规则 | 规则名称进入编辑 | 原文未列删除/停用；由 `DEC-PRD-027` 决定 |
| 编辑/删除特殊授权 | 列表明确提供 | 删除立即移除覆盖；确认、日志和重叠记录处理由 `DEC-PRD-026` 决定 |
| 查看授权结果 | `PRD-03` | Service 返回可见/可订、来源、匹配记录和拒绝原因，不写数据 |

商品下架仍由 `PRD-001` 在订单可选阶段拒绝；授权结果不能把下架商品变为可订。客户非启用状态由 `CUS-001` 先拒绝下单；授权记录可以保留但不能绕过客户状态。

### 状态、时间与冲突解析

- 方案已知状态只有启用/停用；规则是否有状态、方案停用是否立即撤销、特殊授权有效期端点和跨日周期均未定义。
- `PRD-03` 明确客户只看到授权方案和特殊授权覆盖的商品，因此“没有任何有效授权”的默认结果倾向于不可见/不可订，但仍需由 `DEC-PRD-002` 固化。
- 多方案建议按商品集合并集提供授权；特殊授权按客户+商品覆盖方案结果；`禁止 > 仅可见 > 可见+可订`；同类特殊授权重叠应拒绝而不是靠记录顺序决定。完整推荐和影响写入 `DEC-PRD-002/026`，未决定前不实现解析。
- 所有时间判断使用企业时区 `Asia/Shanghai` 的可控 Mock clock，不依赖真实定时器；是否采用分钟精度和 `[开始,结束)` 端点由 `DEC-PRD-026/027` 决定。

### 权限与数据范围

全局权限只确认超级管理员对商品完整读写，销售主管/业务员/仓库为只读或部分，财务不可见。`PRD-001/002` 已决定普通角色不写商品/价格，但授权页面包含客户名单和客户范围，是否向业务员/仓库展示全部客户关联没有来源，登记 `DEC-PRD-029`。路由、UI 和 Service 必须采用同一结果。

### 页面状态与 Mock

| 场景 | 必须表现 |
|---|---|
| normal | 至少两个方案、一个定时规则和三类特殊授权，能解释方案、规则和覆盖来源 |
| empty | 无方案/规则/特殊授权；管理员有新增引导，无授权解析返回明确拒绝 |
| error | 主请求失败可重试；命令失败不修改 Repository |
| slow | 列表/表单显示加载，保存期间禁重复提交 |
| permission-denied | 路由、UI、Service 同层拒绝不可见或只读角色 |
| partial-failure | 商品或客户 provider 单独失败；现有授权记录保留，关联字段显示不可用且禁止空覆盖 |
| boundary | 同刻起止、重叠特殊授权、停用方案、非启用客户、下架商品、重复方案商品和范围空集可重复验证 |

唯一 baseline 应包含固定 clock、方案、计划商品集合、规则、客户范围和特殊授权；商品与客户引用来自已完成 provider，不复制两领域 fixture。CSV、教程和导出均为明确 fake adapter，不访问外部系统。

### 验收追踪

| 契约/规则 | 自动验证 | 人工验证 |
|---|---|---|
| `PRD-10` 范围集合 | 分类/品牌交集、显式商品并集、去重、动态引用测试 | 表单选择变化与商品明细一致 |
| 方案/规则/特殊授权 | Schema、状态、引用、时间和事务回滚测试 | 新增、编辑、停用/删除动作及原因可见 |
| `PRD-03` 授权解析 | 无授权、方案、时段规则、三类特殊授权和冲突优先级测试 | 同客户/商品随时钟变化仍可解释来源 |
| 上下游前置 | 非启用客户、下架/删除商品、停用资料测试 | 页面明确区分“未授权”和“商品/客户不可用” |
| 权限/数据范围 | 路由、UI、Service 角色矩阵测试 | 各角色检查客户名单与写按钮 |
| 页面状态/Mock | normal/empty/error/slow/denied/partial/boundary | 1280px、键盘、错误恢复、截图和控制台 |
| 可恢复 | `mock:reset` 哈希一致、全仓验证 | 干净停止/启动后黄金旅程可重复 |

黄金旅程设计：重置 baseline → 新建含分类/品牌交集及额外商品的启用方案 → 关联启用客户并确认授权 → 新建定时规则并在时段前后推进 clock → 给同一客户/商品依次验证“可见+可订、仅可见、禁止”覆盖 → 停用方案或删除特殊授权后重新解析 → 下架商品仍不可订。决策、实现和全部证据完成前不得宣称本旅程通过。

### 待人工决定的推荐方案

- `DEC-PRD-002`：默认无授权即不可见/不可订；启用方案和当前生效规则命中的商品取并集并提供“可见+可订”；有效特殊授权覆盖方案，优先级 `禁止 > 仅可见 > 可见+可订`；下架商品和非启用客户的领域前置拒绝优先于授权结果。
- `DEC-PRD-023`：方案不建立父子继承，原文“树形”解释为按分类范围分组展开；名称同企业唯一且≤40字；编码自动 `AUTH-000001`、不复用；新增默认启用；停用立即不参与解析但保留引用；被规则引用时禁止删除，其他情况标记删除并留日志。
- `DEC-PRD-024`：分类可多选且含后代，品牌可多选；两组都非空时为 `(分类并集 ∩ 品牌并集)`，只有一组时使用该组，两组都空时范围为空；再与显式 SPU 并集并去重。范围动态引用当前商品资料；只有上架商品进入可订解析，已保存下架项保留回显。详情关联方案统一把当前 SPU 加入显式商品集合。
- `DEC-PRD-025`：方案可直接关联启用客户，表示全天长期生效；规则是额外的定时客户关联，两者取并集。停用方案使两种关联都不生效；客户关联和规则引用保留以便恢复。
- `DEC-PRD-026`：特殊授权按客户×SPU 保存，批量操作展开为原子明细；时间精确到分钟且使用 `[开始,结束)`，开始必填为当前或未来、结束可空且必须晚于开始；同一客户/SPU 的有效期不可重叠。备注可空≤500字。仅启用客户/未删除商品可新增；旧记录保留；删除为标记删除并写日志。
- `DEC-PRD-027`：原型只实现每周周期，至少选择一天；多个时段各自 `开始<结束`、同日不可重叠、不跨日，端点 `[开始,结束)`，企业时区 Asia/Shanghai。规则无额外状态，编辑和删除可用；停用关联方案时规则保留但不命中；名称同企业唯一≤20字。
- `DEC-PRD-028`：原型统一 UTF-8 CSV fake adapter；先保存方案后按 `productCode` 导入显式商品，一行一个 SPU，预览逐行校验，重复去重提示，任一错误整批拒绝。导出选中方案优先，否则导出当前结果；导出方案头和解析后的去重 SPU 明细，不导出客户敏感资料。
- `DEC-PRD-029`：超级管理员完整读写/导入导出；销售主管只读全部方案、规则和特殊授权；业务员只读授权解析结果，不进入含全部客户名单的配置页；仓库只读商品详情的“是否可订”结果且不显示客户；财务不可进入。三层一致。
- `DEC-PRD-030`：方案列表按名称搜索/状态筛选，规则按名称/方案筛选，特殊授权按客户关键字/类型/有效状态筛选；默认创建时间倒序、30条分页。方案列表不用虚构父级树，按分类范围分组可展开；写操作仅显示原文明示或上述生命周期必要动作，保存/保存并新增及脏数据确认沿用全局规范。

上述方案目前只是推荐，不是已决定事实。`DEC-PRD-002、023～030` 全部写回前，`PRD-003` 保持 `source-only`，禁止进入 implementation。
