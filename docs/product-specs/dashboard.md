# Dashboard 规格

## 需求来源与事实边界

- 直接业务来源：[01-整体架构与首页.md](../references/requirements/01-整体架构与首页.md) §3；全局交互与权限资料来自同文件 §4～§5。
- 功能 ID、依赖和字段准备度以 [产品规格索引](index.md) 的 `DASH-001` 为准。
- 原始需求明确的区域、字段和跳转属于业务事实；指标计算、聚合容错和 Mock 组织若原文未定义，只能作为明确标注的工程方案，不能冒充业务口径。
- `DASH-001` 为 `source-only` 时只能提取规格，不能实现未定义指标。

## DASH-001 字段与交互契约

### 事实来源

原始字段来自 `docs/references/requirements/01-整体架构与首页.md §3、§3.3～§3.6`；页面、角色和状态来自同文件 `§4～§5`；订单、资金、库存、客户和设置只通过公开只读 provider。

### 页面与导航

`/dashboard` 四区为待办、营业情况、预警中心和通知公告；待办跳转已有订单、库存、资金和客户路由，不创建重复页面。

### 筛选与列表

首页按当前角色和 Asia/Shanghai 当前自然日加载；通知按未读/全部筛选，预警按类型和处理状态筛选；趋势维度仅保留日/周/月选择，不伪造未接入对比值。

### 表单与校验

待办自定义首版只读默认集合；通知已读和全部已读为 fake 本地命令；日期范围必须是合法自然日闭区间，刷新失败不清空上一次成功结果。

### 详情与操作矩阵

待办卡片点击进入带筛选 query 的既有页面；超级管理员可见全部，销售主管看订单/客户，仓库看库存/出库，财务看收款/应收；不允许从首页修改业务单据。

### 状态与计算

指标使用 provider 返回的整数分/数量；provider 不可用显示 `unavailable（来源未接入）`；今日口径按 Asia/Shanghai，环比/同比和复杂趋势保持 unavailable。

### 页面状态与 Mock

支持 normal、empty、error、permission-denied、partial-failure；某一 provider 失败只影响对应卡片/列表，不把失败转换为 0。

### 验收追踪

| 追踪项 | 规格结果 | 计划验证 |
|---|---|---|
| 四区工作台 | 待办、营业、预警、通知 | 聚合 service 与页面状态测试 |
| 角色边界 | 待办和入口按角色过滤 | 角色切换、跳转 query 和 1280px 浏览器检查 |

### 页面与数据

`/dashboard` 包含待办事项、营业情况、预警中心、通知公告四个区域。待办项为待审核订单、待财务审核、待出库、待发货、待签收和待处理退款；营业卡片为今日订单数、今日销售额、今日收款额和待收金额；趋势区显示销售额/订单量趋势；预警区显示库存不足、订单超时、应收逾期和客户风险；通知区显示系统通知、公告和已读状态。

Dashboard 只调用 Order/Finance/Inventory/Customer/Settings public provider，不保存或修改业务单据。缺失 provider 返回 `unavailable` 并显示来源，不以 0 替代；同比、环比和复杂趋势在原型中保持 unavailable。当前自然日按 Asia/Shanghai 计算。

### 操作与权限

待办卡片点击进入已有模块并附带筛选 query；通知支持单条/全部已读的 fake 本地状态。超级管理员可见全部；销售主管可见订单、客户和公告相关项；仓库可见库存/出库；财务可见收款/应收；无权限区域不显示。支持 normal、empty、error、permission-denied。

## 目标

让管理者和岗位人员进入系统后立即知道当前业务概况、需要处理的事情以及风险，不替代各领域的明细页面。

## 页面范围

- 待办事项：默认待办卡片及用户自定义待办。
- 营业情况：核心指标卡片、时间范围和趋势图表。
- 预警中心：库存、资金、业务异常等可跳转预警。
- 通知公告：展示有效公告及未读状态。

原型首版先实现待办、核心指标、预警与公告四区；复杂个性化布局不在首版。

## 行为约束

- 指标必须标注时间范围、单位和口径入口，不展示无法解释的数字。
- 待办按当前模拟用户权限过滤，点击进入对应模块的已筛选列表。
- 预警状态不能只用颜色；已处理项与未处理项可区分。
- 空数据、查询失败和无权限分别呈现。
- 原型数据由各领域 repository 汇总，Dashboard 不直接读取所有 fixture。

## 实现映射

- View：`src/features/dashboard/views/`
- Service：聚合各领域只读 provider，禁止在 Dashboard 修改业务单据。
- Mock：为管理员、销售、仓库、财务至少准备不同待办集合。

## 验收

1. 默认场景显示四个区域，指标含单位和时间范围。
2. 切换模拟角色后，待办数量和可见入口按权限变化。
3. 点击待办能进入正确目标及筛选状态。
4. `empty/error/permission-denied` 场景呈现不同反馈。
5. 1280px 下信息不重叠，关键待办无需横向滚动。

## 非目标与缺口

不实现实时大屏、自由拖拽布局或生产级数据分析。日界线、纳入状态、超时/风险阈值和同比环比边界按 `DEC-DASH-001` 决定，不能自行计算。
