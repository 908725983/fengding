# 安全边界

## 当前边界

本项目是浏览器内 Vue 3 + Mock 原型。登录、权限、文件、支付和第三方服务都是产品行为模拟，不能证明生产身份认证、租户隔离、加密、审计合规或支付安全。

## 秘密与数据

- 不提交密码、令牌、Cookie、私钥、支付参数或真实第三方凭据；敏感 `.env*` 不进入版本库。
- fixture 不使用真实客户姓名、电话、地址、位置、账号、订单或资金数据。
- 日志、错误和验收截图不得暴露凭据、本机路径、堆栈或完整敏感字段。

## 不可信输入

- URL、富文本、文件名、导入内容和外部响应都按不可信输入处理，并提供校验失败路径。
- Vue 文本插值是默认输出方式；`v-html` 默认禁止，确需使用时先建立净化策略和专门测试。
- 外部链接采用安全打开方式；不得自动请求位置、摄像头、麦克风、通知或文件上传权限。

## 外部与高风险动作

- 导入导出、打印、支付、消息、地图、企微、AI 等只使用 fake adapter，界面明确显示“原型模拟”。
- 破坏性操作必须展示对象、影响和不可逆结果并二次确认；默认不允许作用于真实或生产数据。
- 权限在路由、UI 与 service command 三层模拟，但前端隐藏按钮不是安全控制。
- 新依赖、真实网络调用或生产级操作先写入 active plan，说明必要性、数据流、批准点、回退和安全验证。

## 真实集成前必须补齐

认证与会话、服务端授权和数据范围、多租户隔离、CSRF/CORS/CSP、输入校验、速率限制、审计、加密、备份、隐私与漏洞响应。支付、企微、地图、消息、文件或 AI 还需要供应商协议、凭据管理、回调验签、重试幂等、数据最小化和错误码规范。

## 每个切片的安全验证

确认 fixture 无真实数据、无新增秘密、无未经评审的 `v-html`、权限不只依赖前端隐藏、错误不泄露内部信息、外部能力明确标记为模拟。发现问题时写入当前 active plan；已确认但决定延期的工程风险才进入技术债台账。
