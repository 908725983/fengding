# 原型安全边界

## 当前保证与非保证

本项目是浏览器内 Vue 3 + Mock 原型。权限、登录、文件、支付和外部服务均为交互模拟，不能证明生产身份认证、数据隔离、加密、审计合规或支付安全。

界面和验收必须明确这一点，不得把前端隐藏按钮、LocalStorage 状态或 fake adapter 描述成真实安全控制。

## 强制规则

- 不提交密码、令牌、Cookie、私钥、支付参数或真实第三方凭据；`.env*` 中的敏感值不进入版本库。
- 不使用真实客户姓名、电话、地址、位置、账号、订单或资金数据；fixture 只使用明显虚构内容。
- Vue 默认文本插值可以使用；`v-html` 默认禁止，确需使用时先建立净化策略和专门测试。
- URL、富文本、文件名和导入内容均视为不可信输入；即使原型只模拟，也要展示校验失败路径。
- 权限在路由、UI 和 service command 三层检查；Mock 权限只验证产品行为，不是安全边界。
- 错误信息不得暴露本机路径、堆栈、凭据或完整敏感字段。
- 日志和验收截图不记录敏感内容；敏感字段默认遮蔽，需求未定义角色范围时采用最小可见原则。
- 外部链接使用安全打开方式；不自动上传文件、不请求位置、摄像头、麦克风或通知权限。
- 新依赖先说明必要性和供应链影响；安装成功不等于安全审查通过。

## 真实集成前的阻塞项

接真实后端前必须另行设计：认证与会话、服务端授权和数据范围、多租户隔离、CSRF/CORS/CSP、输入校验、速率限制、审计、加密、备份、隐私和漏洞响应。

接真实支付、企微、地图、消息、文件或 AI 前必须获得供应商协议、凭据管理、回调验签、重试幂等、数据最小化和错误码规范。当前 fake adapter 不能直接替换为网络请求后就宣布完成。

## 安全验收

每个功能至少检查：fixture 无真实数据；无新增秘密；无未审查 `v-html`；无仅靠前端隐藏的权限；错误不泄露内部信息；外部能力明确标记模拟。发现问题时按 `ENGINEERING_GUARDRAILS.md` 的 A 类处理。
