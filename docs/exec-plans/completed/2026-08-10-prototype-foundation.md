# 原型 Harness 与应用壳基线

- 类型：harness
- 功能：HNS-001,SHELL-001
- 当前阶段：verification
- 状态：completed
- 完成日期：2026-08-10

## 目标

建立可干净启动、可导航、可机械检查的 Vue 3 + Mock 原型仓库，并让后续 AI 能从仓库找到产品、业务、架构、计划和验收事实。

## 范围与非目标

范围包括 Harness 基线、八领域需求规格、需求快照、Vue 应用壳、确定性 Mock、测试与构建入口。不实现订单、库存等业务页面，不连接真实后端或外部系统。

## 事实来源

- 八份后台管理端需求文档及仓库内快照。
- Harness Engineering 指南第 100 页以后关于短入口、深链接、计划和验证的原则。
- 用户提供的参考截图，仅用于抽象信息密度与布局习惯。

## 验证路径

- `npm run verify:harness`：导航、规格、需求哈希与规则覆盖通过。
- `npm run typecheck`：通过。
- `npm run test:run`：3 个测试通过。
- `npm run build`：生产构建通过。
- Mock baseline 可恢复到 `work/mock-state.json`。
- 浏览器在 1280px 与 720px 下导航和布局可用，控制台无警告或错误。

## 风险与阻塞

- 业务功能尚未实现，应用壳通过不能当作业务完成证据。
- 商家与独立数据分析缺少详细需求；真实第三方能力只允许模拟。
