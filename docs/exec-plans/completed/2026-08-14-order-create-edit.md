## 风险与阻塞

- 原文包含客户价、等级价、会员折扣、客户分类折扣、行折扣、手工价、整单折扣、促销和优惠券，但没有给出完整组合顺序。
- 原文要求自动占用预收款，却没有金额、更新、失败及释放规则；资金基础能力尚未完成。
- 原文说创建订单不预占库存，但索引仍保留库存预占决策，需要明确本切片只做可售校验还是产生库存副作用。
- “保存并结算出库”跨越审核、资金和出库切片，不能据按钮名称提前跳过状态机。
- 订单号、可编辑状态、重复商品、舍入、地址快照、附件、批量录入和分享过期等规则需要从原文确认或登记决策。

## 已确认方案（2026-08-14）

- 定价按预营销价 → 分类折扣 → 会员折扣 → 单一商品促销 → 优惠券 → 人工行价 → 整单优惠 → 运费执行，逐阶段到分并保存来源；未接入营销 provider 明确 unavailable。
- 建单/审核不预占或扣减库存；保存自动占用 `min(可用预收,订单金额)`，按剩余新增应收校验信用，修改原子调整差额。
- 单号 `CA-YYMMDD-#####`；保存为待订单审核，无草稿；F8 当前禁用；仅待订单审核可编辑并使用乐观锁。
- 客户、仓库、SKU、单位、数量、赠品、金额、收货、发票、附件、模板/粘贴/扫码、权限、分享和失败恢复按 `orders.md` 的 `DEC-ORD-014～027` 已确认条款执行。
