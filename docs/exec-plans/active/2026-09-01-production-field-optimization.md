# 生产级主流程字段优化

- 类型：business-batch
- 功能：CUS-001,PRD-001,ORD-002,ORD-004,ORD-005,PUR-002,INV-001,FIN-001
- 风险等级：L3
- 当前阶段：verification
- 状态：active
- 最近更新：2026-09-01

## 目标

依据用户确认的字段精简方案，降低销售、采购入库和客户退货退款主流程的首屏填写负担；保留底层字段、快照和跨模块关联，确保库存、金额、应收应付和退款守恒不变。

## 范围与非目标

- 范围：客户、商品、销售订单、采购订单/入库、客户退货、收款表单的字段展示、默认值、条件显示和直白文案。
- 非目标：不删除底层实体字段，不改变 SPU/SKU 内部关系，不接入真实支付、文件、物流或第三方服务。
- 本批次暂不扩展：拼套商品、真实发票、真实附件、换货、自动调价和复杂多地址后台。

- `docs/product-specs/customers.md`、`products.md`、`orders.md`、`procurement.md`、`inventory.md`、`finance.md`：当前领域契约。

## 实施批次

- [x] P0：商品新建表单隐藏 SPU/展示分类/规划中选项，默认基本单位和默认 SKU，价格与自定义属性分层。
- [x] P0：客户新建表单移除资质预置属性和客户权限设置，条件化财务、地址字段；未分配业务员由服务端默认当前操作人。
- [x] P0：销售订单商品行隐藏类型/原因，库存与单价只读，折扣和运费按元录入。
- [x] P1：采购订单供货价只读并按元显示，其他费用收进高级项；入库批次/生产日期按追踪规则说明。
- [x] P1：客户退货退款方式移到财务确认，退货金额按原订单单价自动计算并只读；收款表单移除虚构凭证和预收伪收款方式。
- [x] P1：其他出库/入库要求填写业务原因；入库移除供应商自由文本引用，成本按元录入。
- [x] P2：已更新商品/采购专项测试；类型检查、专项 Vitest 与生产构建均通过。
