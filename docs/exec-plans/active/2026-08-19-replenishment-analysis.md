# PUR-001 补货分析与快速采购

- 类型：business-feature
- 功能：PUR-001
- 当前阶段：specification
- 状态：active
- 最近更新：2026-08-19

## 目标

从采购原始需求、库存公开 provider、订单已确认事实和 `PUR-004` 供应商公开 provider 中提取补货分析与快速采购的可编码契约。先固化输入字段、缺货/安全库存分析、建议数量、预估采购价、筛选范围、人工调整和后续采购单交接边界；在决策完成前不创建采购单、不写库存或应付事实。

## 范围与非目标

范围包括按安全库存、按缺货、按安全库存与缺货三类分析；商品分类筛选、统计卡片、补货建议列表、导出；按库存采购和按订单采购两个快速采购选择器；快速采购结果列表的来源标记和向 `PUR-002` 的交接契约。

非目标包括采购订单字段/状态/入库事务（`PUR-002`）、采购退单（`PUR-003`）、供应商主数据与供货关系（`PUR-004` 已完成）、采购统计（`PUR-005`）、库存余额写入、应付形成和真实智能预测。当前不得因快速采购按钮提前创建采购订单、库存流水或应付。

## 风险与阻塞

- 原文只说“基于库存水位、安全库存、缺货情况自动生成”，没有建议补货公式、综合分析去重或缺货定义。
- `INV-001` 当前库存已实现，但待出库、可用库存和采购在途依赖尚未实现的 provider；不能用 0 或空数组代替 unavailable。
- `PUR-004` 有多供应商、首选和采购单位，但快速采购是否只用首选、无首选如何处理、价格是否可手工覆盖仍需固化。
- “一键生成采购订单”跨入 `PUR-002`，快速采购本切片只能形成可解释的候选草稿/交接，不应直接落单。
- 按订单采购涉及订单状态、出库状态、收款状态、配送方式和未设置交货时间订单，原文列筛选但未定义默认值、组合逻辑和快照时点。
