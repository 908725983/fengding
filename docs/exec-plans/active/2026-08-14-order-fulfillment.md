## 风险与阻塞

- 订单原文同时存在订单八状态、出库单“待出库/部分出库/已出库”筛选和“待审核/已审核”字段，状态对象及含义冲突，不能合并猜测。
- 原文允许部分出库并自动生成差异单，但未说明每次部分出库都生成、最终短装才生成，或差异确认后的补发/退款/忽略如何影响订单。
- 出库作废要求保留并重新出库，但没有定义库存冲销、订单已出数量、物流/签收限制、原因和权限副作用。
- 签收记录只有字段，没有多次签收、操作者、前置状态、签收后订单完成和差异处理的完整规则。
- 已确认跨订单/库存/资金边界需要原子、幂等和可回滚；实现中若现有 Repository 无法满足，不得用先成功后补偿的 UI 假象掩盖。
