# 待确认问题台账

## 使用规则

- 本文件只记录影响设计或实现、但现有事实无法回答的问题。
- A 类阻塞相关最小功能；B 类只延期局部能力；C 类由全局规范给出可逆默认值。
- 新问题必须写来源、影响、当前处理和需要谁确认，不能只写“待定”。
- 用户确认后，将结论写入 `DECISIONS.md`，同步更新规格，并把本条状态改为 resolved。
