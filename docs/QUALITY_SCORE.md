## 评分标准

| 等级 | 含义 |
|---|---|
| A | 行为完整，自动与人工路径均有可重复证据 |
| B | 主路径可用且有验证，仍有明确的次要缺口 |
| C | 只有基础或局部实现，关键路径不能完整验收 |
| D | 未实现、不可验证，或不能可信宣称完成 |
